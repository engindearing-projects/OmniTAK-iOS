# OmniTAK iOS 2.18.0 (build 26051104) — SAR closeout

Branch: `feat/closed-test-feedback-may2026` (merged S2 + S3).

Coherent post-integration release tag covering the full 3-session
SAR closeout described in `OmniTAK-Android/docs/sar-multi-session-plan.md`.
Folds in S2 (Mark-My-Position + Mission KML bundle) and S3
(drawing CoT broadcast + Bullseye parity).

## What's new

### Drawings share over TAK (S3)
- Every line, polygon, circle, and bullseye saved in OmniTAK is now
  serialized to CoT (`u-d-f` for line/polygon, `u-d-c-c` for circle
  and bullseye rings) and broadcast through `TAKService.shared.sendCoT`
  to every connected server. Cross-platform: a drawing made on the
  Android peer appears on iOS and vice-versa, plus on any third-party
  ATAK / TAK Server CIV client.
- Incoming `u-d-*` events are ingested back into `DrawingToolsManager`
  so peer drawings render on the local map.

### Bullseye primitive (S3)
- New drawing kind: concentric rings at 100 m / 500 m / 1 km defaults
  (radii configurable in code; UI customisation is the next iteration).
- Mission KML export now includes bullseye rings as 64-segment polygons,
  matching the Android exporter — CalTopo/Google Earth handoffs
  reproduce the SAR-standard ring set exactly.

### Mark-My-Position FAB (S2)
- New FAB in the map control cluster, below the GPS-lock button. Drops
  a friendly point marker at the current GPS fix with an auto-generated
  `MyPos-HHMM` UTC callsign and fans the CoT out via
  `TAKService.shared.sendCoT`.
- Parity with Android vc40 `PinDrop`: same callsign format, so a mixed-
  platform pair drops in the same minute and sees matching labels.

### Mission KML export (S2)
- Settings → MISSION → "Export mission as KML" bundles every point
  marker, drawing, and recorded track into a single KML 2.2 document
  and hands it to the system share-sheet. Affiliation-tinted marker
  styles, 64-point circle approximation, per-track folders.

## What's new

### Mark My Position (one-tap)
- New FAB in the map control cluster, directly below the GPS-lock
  button. Drops a friendly point marker at the current GPS fix with an
  auto-generated `MyPos-HHMM` UTC callsign, persists it through
  `PointDropperService`, and fans the CoT out via
  `TAKService.shared.sendCoT` to every connected server.
- iOS parity with the Android vc40 `PinDrop` FAB — same callsign
  format so a mixed-platform pair drops in the same minute and sees
  matching labels.

### Mission KML export
- Settings → MISSION → "Export mission as KML" now bundles every
  point marker (PointDropperService), drawing marker / line /
  polygon / circle (DrawingStore), and recorded track (TrackRecording
  saved tracks) into a single KML 2.2 document and hands it to the
  system share-sheet.
- Mirrors Android `MissionKmlExporter.kt`: affiliation-tinted marker
  styles, 64-point circle approximation (no native KML circle), and
  a track folder for SAR teams without a per-track export need.

## Closes (K9Blue TROP feedback, 5/9/26)

- "no option for dropping a waypoint/marker on your current position
  … having to lock onto your own position and create a waypoint
  takes a lot of time when we need to be watching our dogs."
- "Exporting Missions is not possible from the app. Which really
  stinks because sometimes we will be asked to provide search data
  on the spot when we do not have a CalTopo file or equivalent."
